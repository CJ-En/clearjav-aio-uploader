ClearJAV account

Paste the announce URL once: it goes into every .torrent the tool makes, so the file is a normal private ClearJAV torrent from the start. The site still makes its own .torrent on upload: that is the one to seed, and the tool saves it, puts it in your watch folder or hands it to qBittorrent (Seeding). The key and the announce URL hold your passkey: they are kept in the place shown above, and never written to the log.

Seeding

After the upload the tool downloads the site's .torrent (the one to seed) and:
Watch folder
The client must save these torrents into the folder where your videos are, or it downloads the video again instead of seeding it. qBittorrent can do that per watch folder ("Monitored folders" → "Download to"); otherwise use "Adds it to qBittorrent".
qBittorrent's Web UI (Tools → Options → Web UI) has its own login; that is why it is asked here. The password is kept in the same place as the API key.
